# Commerce Store

Standalone commerce storefront and admin foundation.

## Current scope
- Polished public storefront
- Product catalogue presentation
- Rental-ready merchandising
- Standalone admin dashboard
- Responsive styling
- Architecture intentionally separate from Sunwings, Wheels, and JustConsignIn

## Run locally
```bash
npm install
npm run dev
```

Open `http://localhost:3000` for the storefront and `/admin` for the admin foundation.
